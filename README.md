# C++ Programming & Object-Oriented Concepts 🚀

Welcome to my C++ repository! This repo contains clean, modular implementations of core **Object-Oriented Programming (OOP)** principles, fundamental **Data Structures**, and practical **C++ programming tasks**.

## 📌 Features & Implementations

### 1. Object-Oriented Programming (OOP)
* **Custom `Complex` Number Class:** Complete implementation covering:
  * Constructors (Default, Parameterized, Deep Copy Constructor) & Destructors.
  * Operator Overloading (`+`, `-`, `*`, `/`, `+=`, `-=`).
  * Increment/Decrement (`++`, `--` prefix & postfix).
  * Comparison operators (`==`, `!=`, `>`, `<`).
  * Stream I/O operators (`<<`, `>>`) and Type Casting.
  * Function call operator overloading `obj()`.

* **Inheritance & Polymorphism:**
  * Base and Derived class hierarchies (e.g., `Shape` / `Geometry` and `Vehicle` multi-level trees).
  * Virtual functions, dynamic binding, and explicit method overriding using `override`.
  * Pointer upcasting and memory safety via virtual destructors.

### 2. Data Structures & Memory Management
* **Stack Class:** Custom dynamic LIFO stack with explicit memory allocation on the heap (`new` / `delete`).
* **Deep Copying:** Deep Copy Constructors and Copy Assignment Operators (`operator=`) handling to prevent shallow copy bugs and runtime crashes.

### 3. General Tasks & String Operations
* **Word Reversal:** Splitting strings and reversing word orders using streams and vectors.
* **Timed Execution:** Loop execution using modern C++ `<chrono>` and `<thread>` libraries.
